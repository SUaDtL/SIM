An arriving engineer and a briefing recipient should work independently without coaching.
Record participant role, browser/version, OS, candidate checksum, viewport, actual zoom,

before recording anything beyond anonymous task observations; do not contact them automatically.

Engineer tasks:

1. Open `enterprise.sqlite`. Find Orders & Fulfilment, edit its Description, then find
   Tier 1 support and its outgoing connections. Return between sections and inspect a
   reference using Back. Explain what is unapplied, applied and saved.
2. Remove its required Name and try Save file. Repair the field, Apply and Save again.
   Explain whether the prior failure remains current. Reopen the saved file and verify it.
3. With keyboard only, add an organization and immediately edit it with F2. Apply, Cancel
   and Stay after a changed draft. Repeat a representative non-service record.
4. Open `four-change-scenario.sqlite`, select Consolidation and predict the effect of
   removing Add Target Portal. Read the consequences, cancel, then confirm. Undo and Redo
   once each. Verify unrelated pending scenario metadata/builder text stays unchanged.
5. At genuine 200% and 400% browser zoom, repeat section navigation, a picker and an error
   correction. With an actual screen reader, identify labels, current section, validation
   messages and removal consequences; verify the completion focus and keyboard continuation.

Briefing recipient tasks:

1. Open `demo-arrangement.sqlite` at a laptop size and Fit map. Identify the seven network
   domains and the partner gateway without hints. Use focus and return to the overview.
2. Capture PNG and SVG in As-Is, To-Be and Compare. Check network/CDS identity, edge endpoints,
   scenario context, markings and caveats in the actual output. Read the result as a briefing.
3. Explain whether the main preview and a versioned release download identify the same
   source. Check About and the delivery record before choosing the offline candidate.

Native file/recovery checkpoint, installed Chrome and Edge:

1. Open the identified HTML directly. Save synthetic work to a new temporary `.sqlite`, edit,
   repeat Save, Save As to a second path and cancel another Save As with the draft retained.
   Reopen both files and inspect readback. Record the actual picker and browser behavior.
2. Select a separate optional recovery file, apply a change and reopen its bytes. Stop and
   retry recovery. Try selecting the primary file as recovery and confirm protection.
3. Exercise external-writer conflicts and the offered recovery paths without overwriting
   valuable files. Check parent-only and child-only unsaved work on reload/close and Stay.
4. If an actual permission refusal occurs, record the refusal and retained state. If none
   appears, record that case as unexercised. Do not manufacture a permission prompt or infer
   cross-process locks, crash/power-loss durability, or browser support from adapters.
