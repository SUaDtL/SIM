# Release proof obligations

This packet does not authorize a merge, tag or public release.

G0: Receiving source and exact built HTML are identified and retained. A successful source merge is not a delivered-file update.

G1: Every finding has a current disposition: reproduced/open, fixed with evidence, already fixed with evidence, inapplicable with reason, or explicitly accepted limitation. Source-derived high-risk gaps receive actual integrated reproduction before being dismissed.

G2: The complete declared code gate passes on the candidate. No weakening tests, skipping failing branches or replacing exact assertions with vague visibility checks.

G3: Every applicable integrated UAT case is executed on the exact offline file. Native API tests using stubs are labelled adapter tests. Native picker, permission, real write/readback, recovery and external-writer outcomes are independently recorded.

G4: Actual screenshots and downloaded captures are inspected in both supported browsers, at normal and actual enlarged zoom, with representative density and long names. No clipped menu, missing action or contradictory displayed state remains.

G5: Synthetic role review is labelled as such. A real uncoached user task is preferred before broad distribution; lack of that study is recorded, not replaced by invented participant statistics.

G6: A non-author reviewer checks fixes, regression coverage and the evidence manifest. Product/source/build identity agrees across all artifacts. Unresolved mandatory blocks prevent a full acceptance claim.

G7: The owner authorizes delivery/release. Verify the bytes at the actual distribution link and provide checksum/version/instructions. Retain supported limitations without hiding them inside developer notes.
