Project skeleton and single-file build

Stand up the SIM repository: strict TypeScript + Vite single-file build to dist/sim.html with inlined sql.js WASM, lint/format, unit and offline file:// e2e tests in Edge and Chrome, one npm run check gate, agent guide, Apache-2.0 license and changelog.

Approach

APP-1

Approach

Binding decision refs
  • DEC-1
ChoiceVite + vite-plugin-singlefile, strict TypeScript, sql.js imported with ?url so the WASM is inlined as a data URL and passed as wasmBinary, ESLint (typescript-eslint) + Prettier, Vitest, Playwright using the installed msedge and chrome channels with the context offline and http(s) aborted. Only one sane approach exists: the ADR-0001 stack with the settings proven by the file:// spike.
TradeoffPlaywright uses the installed browsers rather than downloading its own, so e2e depends on Edge and Chrome being present on the machine.
