Sections

SEC-SMARTS

Design rationale

Blocks

Chosen-file recovery follows explicit user selection and forbids browser persistence. Exact bytes detect changes missed by timestamp and size; reliability favors bytes, other lenses indifferent. Native cross-process races remain a declared limitation.
