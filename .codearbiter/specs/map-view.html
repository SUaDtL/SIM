Map view

The center region draws the dataset as a Cytoscape.js map: networks as containers holding their services, an external zone, CDS nodes between the networks they join, and dependency edges styled by whether they stay local, pass through a CDS, cross a boundary without one, or reach an external service.

Approach

APP-1

Approach

Binding decision refs
  • DEC-1
  • DEC-2
  • DEC-3
ChoiceA pure graph model (src/map/graph.ts) turns repository.snapshot() into Cytoscape element definitions with unique IDs and edge classes; a map view (src/map/map-view.ts) mounts Cytoscape with the fcose layout in a sized container, updates elements incrementally on repository changes and opens tapped nodes in the editor.
TradeoffThe pure model is the main test oracle; the canvas is checked in e2e through the Cytoscape container registry rather than a test-only global.

Library and layout

Authorityinherited
ChoiceCytoscape.js with fcose only, bezier edges, tiled packing of unlinked services.
RationaleADR-0001 and Q-023; layout spike.

DEC-2

CDS routing

Authorityinherited
ChoiceA via-CDS dependency is drawn as two edges, consumer to CDS and CDS to provider, each keyed by its dependency so IDs never collide.
RationaleSpike: CDS between the networks it joins; unique IDs avoid Cytoscape add failures.
