# Security policy

SIM runs entirely in the browser with no network access; its Content Security Policy and test
suite enforce this. To report a vulnerability (for example a way to make the app send data, run
injected script from a crafted `.sqlite` or CSV file, or bypass file-safety checks), use
[GitHub private vulnerability reporting](https://github.com/SUaDtL/SIM/security/advisories/new)
rather than a public issue. Do not include real or sensitive network data in reports.
